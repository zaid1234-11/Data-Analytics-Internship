# Sales Data Analysis Project

## Project Overview
This repository contains a comprehensive data analytics portfolio project focused on retail sales and customer behavior. It analyzes retail transaction data to identify purchasing patterns, revenue trends, and the effectiveness of marketing campaigns. The project demonstrates end-to-end data analytics skills, including data cleaning, exploratory data analysis (EDA), SQL querying, and data visualization.

## Repository Structure
- **`/notebook/retail_analysis.ipynb`**: The core Jupyter Notebook containing Python code for data loading, cleaning, EDA, visualizations, and customer segmentation logic (classifying customers as High, Medium, and Low-value based on percentiles).
- **`/sql/retail_analysis.sql`**: SQL scripts for database creation, table schema setup, and analytical queries to extract key business metrics directly from the raw data.
- **`/dashboard/Retail_Dashboard.xlsx`**: An interactive Excel dashboard featuring KPI cards (Total Revenue, Average Transaction Value, Total Customers, Response Rate) and visual charts showcasing monthly revenue trends and response distributions.
- **`/ppt/Retail_Analysis_Presentation.pptx`**: A 10-slide professional PowerPoint presentation summarizing the project objectives, methodologies, key findings, and actionable business recommendations.
- **`/data/`**: Contains the raw datasets used for the analysis (`Retail_Data_Transactions.csv` and `Retail_Data_Response.csv`).

## Key Findings
- **Total Revenue**: $8,122,062 generated across the analyzed period.
- **Customer Engagement**: The marketing response rate was approximately 11.1%.
- **Revenue Trends**: Significant revenue peaks were identified during specific late-summer months.
- **Customer Segmentation**: A small segment of top customers contributed significantly to the overall sales volume.

## Tools & Technologies Used
- **Python** (Pandas, Matplotlib, Seaborn)
- **Jupyter Notebooks**
- **SQL** (Data Extraction & Aggregation)
- **Microsoft Excel** (Data Visualization & Dashboards)
- **PowerPoint** (Presentation)

## Recommendations
1. Focus targeted marketing efforts on the identified high-value customers.
2. Increase promotional activities during historical low-revenue months to drive traffic.
3. Improve campaign targeting strategies to increase the 11.1% response rate.
4. Develop tailored loyalty programs to retain and reward repeat customers.
